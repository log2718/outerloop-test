The baseline is already well-optimized for the constraints:
1. Deeper architectures add parameters that overfit on 400 samples
2. Multi-layer networks force feature compression at intermediate layers, losing signal
3. Regularization (dropout, input norm) provides minimal benefit
4. The 10:6 noise-to-signal ratio combined with small dataset size creates a fundamental performance ceiling

### Takeaways
1. Single-layer architecture is appropriate for this dataset size
2. Current hyperparameters (hidden_size=10, lr=0.008) are near-optimal
3. Regularization doesn't help—the model isn't overfitting; it's capacity-limited
4. The problem has intrinsic limits: 400 samples, 4 classes, high noise content
