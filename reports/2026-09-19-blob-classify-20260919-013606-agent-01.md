### Why It Underperformed
The baseline is genuinely at a local optimum for this architecture. The fundamental constraints are hard limits:

1. **Small sample size with high class cardinality**: 400 samples / 4 classes = 100 per class limits what any model can learn
2. **Overwhelming noise**: 10 pure noise features (uncorrelated with labels) competing with 6 informative ones
3. **Low signal-to-noise ratio**: Class separation 0.5 vs. noise std 1.5, giving SNR ≈ 0.33
4. **Well-tuned baseline**: The current configuration (hidden_size=10, lr=0.008) was already optimized from prior work (improved from 0.475 to 0.495)

Adding capacity, regularization, or preprocessing all hurt because:
- Larger hidden sizes (11+) overfit on 400 samples
- Smaller hidden sizes (≤9) lose information
- Dropout/normalization add complexity that doesn't generalize
- Projection layers force lossy compression

This is a negative result reported clearly. The model has reached the practical ceiling for single-hidden-layer MLPs on this constrained dataset.
